# 大富豪 オンライン対戦

## ダウンロード
[Releases](https://github.com/uruurus15/Secret-Millionaire/releases/latest) から `Daifugo.exe` をダウンロードして、ダブルクリックで起動する（Windows 10/11、インストール不要）。

- 初回起動時に「WindowsによってPCが保護されました」と出たら、「詳細情報」→「実行」を押す（署名のない個人製アプリのため表示される）
- 「Windows セキュリティの重要な警告」（ファイアウォール）が出たら「アクセスを許可する」を押す（部屋を作る人のみ必要）

## 起動

| ファイル | 用途 |
|---|---|
| `dist\Daifugo.exe` | アプリ本体。ホストとして部屋を作る / 友達の部屋に入る |
| `dist\DaifugoServer.exe` | 画面なしの常設サーバー（`DaifugoServer.exe --port 8765`） |

### 遊び方
1. ホスト役が `Daifugo.exe` → 「ホストとして開始」。ロビーに表示されたアドレス（例 `192.168.1.2:8765`）を友達に伝える
2. 友達は `Daifugo.exe` → 「部屋に入る」にアドレスを入力 → 部屋番号を選んで参加
   - アプリが無くても、ブラウザで `http://<アドレス>/` を開けば参加できる
3. ホストがモード・ルールを決めて「対戦開始」。人数が足りなければ CPU を追加できる（2〜6人）

### インターネット越しに遊ぶ場合
- 初回起動時の Windows ファイアウォールの確認は「許可」を選ぶ
- 同じLAN内ならそのまま遊べる。LANの外の友達と遊ぶ場合は次のどれかが必要
  - **Hamachi**（ポート開放不要）：全員が [Hamachi](https://vpn.net) を入れて同じネットワークに参加し、ホストの `25.x.x.x:8765` に接続する（無料版は1ネットワーク5台まで）
  - ルーターで TCP 8765 をホストPCへポート開放し、グローバルIPを伝える
  - Tailscale などの VPN を使い、そのIPを伝える（ポート開放不要）
- ホストのロビー上部に、LAN・Hamachi・インターネット（グローバルIP）の接続先が表示される。「コピー」ボタンでコピーして友達に送れる

### ソロで遊ぶ
`Daifugo.exe` →「ひとりで遊ぶ」でCPUの人数（1〜5人）を選んで開始。このPCの中だけで動き、他の人は参加できない。
ロビーでもCPUの人数を変更できる（CPUの名前は CPU1, CPU2 …）。

ロビーの「残りがCPUだけになったら、ラウンド終了までスキップ」をONにすると、人間が全員上がった時点でそのラウンドの残りを一瞬で終わらせる。

### ロビーの設定
- **持ち時間**：なし／30秒／1分／2分（初期値）／3分／5分。ラウンドごとに満タンに戻る。使い切ると毎手番5秒
  - カードを出す番のほか、7渡し・10捨て・12ボンバー・カード交換・シークレットの効果選択でも消費する
  - 時間切れになると自動でパス（場が空のときは弱いカードを出す）。選択系は自動で選ばれる
- **残りがCPUだけになったらスキップ**：人間が全員上がったら、そのラウンドの残りを一瞬で終わらせる

### 対戦中の表示
- 12ボンバーで指定された数字は、演出のあと画面上部に「💣 12ボンバー：3・4」と場が流れるまで表示される
- 10捨て・12ボンバーで捨てられたカードは、画面上部のチップを押すと場が流れるまで確認できる
- ラウンド結果のポップアップを閉じても、卓の中央の「結果を表示」から開き直せる

## 対戦モード
- **通常モード**：ホストが追加ルールを設定し、全員に公開する
- **ランダム秘匿**：追加ルールが対戦ごとにランダムで決まる。誰にも公開されず、最終結果で公開される
- **シークレット**：毎ラウンド次の順で進む
  1. カードを配る
  2. 大富豪から順に効果を1つずつ選び、好きな数字に割り振る（例：8切りの効果を3に →「3切り」）
     - すでに誰かが選んだ効果は選べない（誰が何を選んだかは非公開）
     - 同じ数字に複数の効果を付けられる（5スキップ・7渡し・12ボンバーを全部8に、なども可）
  3. 大富豪・大貧民などのカード交換
  4. 対戦。ラウンド終了時に効果の割り振りを公開

  | 身分 | 選べる効果 |
  |---|---|
  | 大富豪 | 8切り・5スキップ・ジョーカーの枚数（0〜11枚） |
  | 富豪 | 上記 ＋ 11バック・革命の枚数（3枚から／4枚から） |
  | 平民 | 上記 ＋ 7渡し・10捨て |
  | 貧民 | 上記 ＋ 12ボンバー |
  | 大貧民 | 上記 ＋ 数字を3つ選んで、その数字に割り振られた効果を調べる |

  - 1回戦は身分がないので、ランダムな順番で全員「平民」の選択肢から選ぶ
  - ジョーカーの枚数は配った後に決まるため、増えた分は手札の少ない人に配り、減った分は持っている人から回収する
  - 誰も選ばなかった効果はそのラウンドでは無効（革命は4枚から）

隠しモードでは、効果が発動した時（「3切り！」など）にだけ演出が出る。

## ルール
- 基本：革命あり（同じ数字4枚以上）、階段は同じスートの3枚から、ジョーカー1枚（単体では最強。どのカードの代わりにもなる）
- スペ3返し：ジョーカー単体には♠3を出せる。出した瞬間に場が流れ、♠3を出した人から再開（革命中・縛り中でも有効）
- 強さ：3 < 4 < … < K < A < 2 < JOKER。2回戦目以降は称号に応じてカードを交換し、大貧民から始める

| 追加ルール | 動作 |
|---|---|
| 革命なし | 4枚以上出しても革命が起きない |
| ジョーカー追加 | ジョーカーを +1〜10枚 |
| 8切り | 8を含めて出すと場が流れ、出した人から再開 |
| 11バック | Jを出すと場が流れるまで強さが逆転（もう一度Jで元に戻る） |
| 5スキップ | 5の枚数分、次の人を飛ばす |
| 7渡し | 7の枚数分、次の人に手札を渡す |
| スート縛り（2枚/3枚） | 同じスートが2回（3回）連続で出ると、場が流れるまでそのスートしか出せない |
| 12ボンバー | Qの枚数分だけ数字を指定し、全員がその数字のカードを捨てる（JOKERも指定可） |
| バックナンバー | 9を出すと手番の回る向きが逆になる |
| 10捨て | 10の枚数分、手札を捨てられる |

## 上がり方の指定
ロビーで追加ルールとは別にON/OFFできる。禁止された上がり方をすると**反則上がり＝最下位**（複数いる場合は先に反則した人ほど下）。

| 上がり方 | 初期値 | 内容 |
|---|---|---|
| 革命していない時の2上がり禁止 | ON | 革命していない時に、2を含むカードを出して上がると反則 |
| 7渡し上がり禁止 | OFF | 7渡しで手札を渡し切って上がると反則 |
| 10捨て上がり禁止 | OFF | 10捨てで手札を捨て切って上がると反則 |
| 12ボンバーによる自分手番での上がり禁止 | ON | 自分の12ボンバーで自分の手札がなくなると反則（他人の手札がなくなるのはOK） |
| 8切り上がり禁止 | ON | 8切りになるカードを出して上がると反則 |

- 7渡し・10捨ては「出した枚数ちょうど」渡す／捨てるため、手札が少ないときに7や10を出すと反則になりうる
- シークレットモードでは効果を割り振った数字で判定する（例：8切りの効果を6に割り振った場合、6で上がると「8切り上がり禁止」の反則上がり。8で上がるのは問題なし。7渡し・10捨て・12ボンバーも同様）
- 対戦中は卓の左下の「ルール確認」欄と「ルール」ボタンでいつでも確認できる
- ランダム秘匿モードでは上がり方の指定もランダム。ルール確認欄は最初すべて「？」で、関係するカードが初めて出た時点で判明する
  （2→2上がり、8→8切り・8切り上がり、7→7渡し・7渡し上がり、10→10捨て・10捨て上がり、Q→12ボンバー・12ボンバー上がり、
  J→11バック、5→5スキップ、9→バックナンバー、ジョーカー→ジョーカー追加、4枚出し→革命なし、
  スート縛り→縛りが起きた時か、同じスートが3回続いても縛りにならなかった時）

## 開発
```
pip install aiohttp pywebview pyinstaller pillow
python app.py               # アプリ起動
python server.py            # サーバーのみ
python tests\rules_test.py  # ルールの単体テスト
python tests\sim_test.py    # CPU同士3000試合の整合性テスト
python tests\skip_test.py   # 残りCPUのみスキップのテスト
python tests\clock_test.py  # 持ち時間のテスト
python tools\make_icon.py   # アイコン web\icon.ico を作り直す（必要なときだけ）
pyinstaller --noconfirm --onefile --windowed --name Daifugo --icon web\icon.ico --add-data "web;web" --add-data "launcher.html;." app.py
pyinstaller --noconfirm --onefile --console --name DaifugoServer --icon web\icon.ico --add-data "web;web" server.py
```
